# 🏥 MEDISYNTH
## Hospital Inpatient Discharge Analytics Dashboard

MEDISYNTH is an interactive **hospital inpatient discharge analytics dashboard** developed using **Python and Streamlit**. The application uses data analysis and interactive visualisations to explore patterns in hospital inpatient discharge records.

The dashboard focuses on areas such as **patient demographics, diagnoses, hospital stays, severity of illness, healthcare utilisation and costs**. Interactive filters and visualisations allow users to explore the dataset and identify meaningful patterns.

> **Note:** This project is designed for educational and exploratory data analysis purposes only. It does not provide medical or clinical advice.

---

# 📌 Project Overview

Healthcare datasets contain large amounts of information that can be difficult to understand when viewed only as rows and columns. MEDISYNTH transforms hospital discharge data into an interactive dashboard that makes the information easier to explore and interpret.

The project demonstrates how Python-based data analysis and visualisation tools can be used to examine hospital inpatient discharge data and communicate insights through an interactive interface.


## 4️⃣ Run the Streamlit Application

# ⚠️ Important Limitations

This project has several limitations:

- The deployed version uses a **sample dataset** because the complete dataset is too large for standard GitHub repository storage.
- Results depend on the data available in the sample dataset.
- The dashboard is intended for **exploratory and educational purposes**.
- The results should not be used as medical, clinical or professional healthcare advice.
- Patterns identified in the dashboard should be interpreted within the limitations of the available data.
